
# Bookly - Book Landing Page

## Giới thiệu
Website tĩnh giới thiệu sách được xây dựng bằng HTML, CSS và Bootstrap 5.

## Các chức năng giao diện
- Header và thanh điều hướng responsive
- Book Overview: giới thiệu nội dung sách
- Author: thông tin tác giả
- Features: các đặc điểm nổi bật
- Prices: bảng giá các phiên bản
- Download: liên kết khám phá sách miễn phí
- Reader's Say: đánh giá minh họa từ độc giả
- Footer: thông tin cuối trang

## Công nghệ
- HTML5
- CSS3
- Bootstrap 5
- Responsive Web Design

## Cách chạy
1. Tải hoặc clone repository.
2. Mở thư mục dự án trong VS Code.
3. Mở file index.html bằng trình duyệt.
4. Cần kết nối Internet để tải Bootstrap và hình ảnh bên ngoài.

## Tác giả
Sinh viên thực hiện bài tập thực hành thiết kế website.
